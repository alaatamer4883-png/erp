# نظام أبيكس السحابي لإدارة المؤسسات (Apex Enterprise ERP)

نظام إدارة موارد مؤسسية متكامل واحترافي (Enterprise ERP SaaS) مصمم بالكامل باللغة العربية مع اتجاه الكتابة من اليمين إلى اليسار (RTL)، ويربط كافة الوحدات الخمسة والصفحات ببعضها باستخدام **HTML, CSS, JavaScript** ومربوط بقاعدة بيانات **Firebase Firestore** السحابية التابعة للمشروع `tast-b91f3`.

### 🗄️ المجموعات السحابية المربوطة (Firestore Collections):
1. `erp_invoices`: فواتير العملاء والذمم المدينة والمبالغ وحالات السداد (مدفوعة، معلقة، متأخرة).
2. `erp_products`: دليل المخزون والمنتجات والأسعار والكميات المتاحة ومستويات الأمان.
3. `erp_stock_movements`: سجل حركات وتدقيق المخزون (استلام وارد، صرف صادر، تسوية).
4. `erp_customers`: دليل وحسابات العملاء المعتمدين وسجل المعاملات.
5. `erp_sales_orders`: أوامر البيع وخط السير التفاعلي (جديد ➔ قيد التجهيز ➔ تم الشحن).
6. `erp_suppliers`: بيانات الموردين المعتمدين وتقييمات الجودة وشروط السداد.
7. `erp_purchase_orders`: أوامر الشراء الرسمية والمطابقة الثلاثية (3-Way Matching).
8. `erp_employees`: سجل وملفات الموظفين، الرواتب، الأقسام، والحالة الوظيفية.
9. `erp_attendance_log`: سجل محطة البصمة والحضور والانصراف اللحظي.
10. `erp_leave_requests`: طلبات الإجازات السنوية والمرضية وقرارات الاعتماد/الرفض.

### ⚡ المزامنة اللحظية (Two-Way Real-time Sync):
- عند إنشاء فاتورة جديدة أو تغيير حالتها، يتم التحديث في Firebase فوراً.
- عند إدخال أمر بيع أو نقل مرحلته في الكانبان، يتم الحفظ في Firebase فوراً.
- عند تسجيل حضور أو انصراف في محطة الويب، يتم تسجيل البصمة في Firebase فوراً.
- عند قبول أو رفض إجازة، يتم حفظ القرار في Firebase فوراً.
- يتضمن النظام مراقباً لحظياً (`onSnapshot`) لتحديث الشاشات تلقائياً عند تغيير البيانات في Firebase.

### 🛡️ إرشادات قواعد الأمان (Firestore Security Rules):
لتفعيل القراءة والكتابة للمشروع، يرجى التأكد من ضبط قواعد Firestore في [Firebase Console](https://console.firebase.google.com/) كالتالي:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

## 🚀 كيفية تشغيل واستعراض النظام

1. **الفتح المباشر:** انقر نقراً مزدوجاً على `index.html` في أي متصفح ويب.
2. **عبر الخادم المحلي:**
   ```bash
   node server.js
   ```
   ثم افتح: **`http://localhost:3000`**

## 📂 بنية الملفات والربط الموحد

- `index.html`: البوابة الموحدة الرئيسية المتكاملة لكافة الوحدات الـ 5.
- `finance.html`: صفحة وحدة المالية والمحاسبة المستقلة المربوطة.
- `inventory.html`: صفحة وحدة المخزون والمستودعات المستقلة المربوطة.
- `sales.html`: صفحة وحدة المبيعات وإدارة العملاء المستقلة المربوطة.
- `purchasing.html`: صفحة وحدة المشتريات والموردين المستقلة المربوطة.
- `hr.html`: صفحة وحدة الموارد البشرية والرواتب المستقلة المربوطة.
- `js/firebase-service.js`: محرك الربط والمزامنة السحابية مع Cloud Firestore.
- `js/app.js`: محرك التوجيه (Routing)، الجداول، الحسابات، النوافذ، والبحث السريع.
- `js/data.js`: قاعدة البيانات التأسيسية المعتمدة لنظام الـ ERP.
- `css/style.css`: نظام التصميم الخاص بالـ SaaS، الخطوط العربية (Cairo & Tajawal)، وتنسيقات الـ RTL.
